# Khasim Bin Saleh

Personal site for an AI/ML engineer in Berlin. Phase 1 is the shell and the home page. Later phases add papers, the learning log, and the command palette.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. German UI is at http://localhost:3000/de.

## Checks

```bash
npm run lint
npm run build
```

A short guide for adding a weekly paper or learning entry comes in a later phase.
